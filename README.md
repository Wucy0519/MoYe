# 墨页 · 用户使用手册

墨页是一款自用的 macOS Markdown 阅读和编辑器。你可以编辑本地 Markdown 文件，同时查看排版结果。支持 macOS 14 及以上，当前应用适用于 Apple Silicon Mac。

## 功能一览

- **本地写作与阅读**：新建、打开和保存 Markdown 文件，多文档独立窗口，编辑／双栏／阅读三种模式。
- **实时预览**：标题、加粗、斜体、删除线、引用、链接、代码、表格、列表、任务列表和本地图片。
- **双向滚动同步**：在双栏模式中，滑动任意一栏，另一栏跟随；也可关闭同步，分别阅读。
- **选区快捷操作**：纵向浮动菜单设置字重、斜体、1–6 级标题，并在选区后插入代码块、图片、链接、表格和列表。
- **离线数学公式**：内置 MathJax，支持分数、根式、积分、矩阵和多行对齐；识别选中的 LaTeX 并提供「转换公式」。
- **文档导航**：标题大纲跳转、文件夹及子文件夹中的文档列表、查找和替换。
- **导出和打印**：侧栏导出 HTML，打印或存储为 PDF；PDF 提供正常、较窄和极窄三档页边距。
- **macOS 使用习惯**：Finder 打开方式和右键服务，可选设为 Markdown 默认应用，撤销／重做、自动保存、浅色／深色外观和编辑字号调整。

## 五分钟上手

1. 打开墨页，按 ⌘N 新建文档，输入 `# 我的笔记`。
2. 保持「双栏」模式，输入正文；选中文字，点击浮动菜单的「加粗」或「变为标题…」。
3. 输入 `$\frac{a}{b}$`，右侧即可离线显示分数。
4. 按 ⌘S 保存为 `.md` 文件；需要插图时，使用「格式 → 插入本地图片…」。
5. 写长文时，试着分别滑动左右两栏；点击侧栏大纲中的标题跳转。
6. 分享时，从侧栏导出 HTML，或点击「打印 / 导出 PDF…」存储 PDF。

## 1. 打开应用和文件

双击 `/Users/wcy/Desktop/软件/墨页.app` 启动应用。点击顶部「打开」或按 ⌘O，选择 `.md`、`.markdown`、`.mdown`、`.mkd`、`.mmd` 或 `.txt` 文件。首次使用可以打开开发目录中的 `示例.md`。

首次启动会询问是否将墨页设为 `.md` 的默认打开应用。你可以选择「保留现有设置」或「设为默认」。此设置针对当前 macOS 用户的 Markdown 类型，可能同时影响 `.markdown` 等同类型文件。以后可从「墨页 → 默认打开 Markdown 文件…」重新选择。

按 ⌘N 新建文档。每个文档有独立窗口，可以同时编辑多个文件。

### 从 Finder 右键打开

在 Finder 中右键 `.md` 文件，选择「打开方式 → 墨页」。也可以在右键菜单的「服务」中选择「使用墨页打开」。应用提供了 macOS 服务；若该服务未显示，可在「系统设置 → 键盘 → 键盘快捷键 → 服务」中启用「使用墨页打开」。

## 2. 编辑、预览和阅读

顶部有三个模式：

- **编辑**：只显示 Markdown 编辑区，适合集中写作。
- **双栏**：左边编辑，右边实时显示排版。
- **阅读**：只显示排版后的正文，适合阅读。

右侧预览会显示标题、加粗、斜体、删除线、引用、链接、表格、代码块、任务列表、图片和数学公式。

**双栏默认双向同步滚动**：滑动左侧编辑区，右侧预览会跟随；滑动右侧预览，左侧编辑区也会跟随。在「视图 → 双栏同步滚动」中取消勾选后，两栏可以独立滚动；再次勾选恢复同步。同步按两栏各自的滚动进度定位，源码与排版高度不同，中间位置可能不会逐行对齐。此设置只在双栏模式中生效。

## 3. 选中文字，设置字重和标题

在编辑区用鼠标拖动选中文字，或用键盘选中文字，稍停后会在选区旁弹出纵向菜单，带图标和鼠标悬停提示。

- **加粗**：将选中文字加粗，再次操作可取消加粗。
- **常规字重**：移除选中文字的加粗标记，恢复常规字重。
- **斜体**：切换选中文字的斜体格式。
- **变为标题…**：选择「1 级标题」到「6 级标题」，或选择「恢复正文」。

Markdown 标题作用于整行：即使只选中一行里的几个字，也会把这一整行转换成标题。选中多行时，对每个非空行应用所选级别。更换标题级别会替换原来的级别，例如 `## 标题` 转为 `#### 标题`。在其他位置单击、滚动编辑区或切换模式可收起浮动选项。

浮动菜单横线下方提供插入操作：代码块、本地图片、链接、表格、无序列表和有序列表。插入操作会保留选中文字，内容加在选区末尾；块级内容会自动添加空行。插入后可修改示例文字、网址或代码。插入本地图片前请先保存文档。

常用格式也可以通过顶部「格式」菜单完成；「常规字重」「恢复正文」和选区后插入有序列表可在浮动菜单中选择。阅读区的文字选择用于阅读和复制；要修改格式，请切换到编辑或双栏模式。

### 将 LaTeX 转为 Markdown 公式

选中 LaTeX 公式时，菜单会自动把「转换公式」放在第一项。点击后，会在原位置转换选中内容，操作可撤销。

- `\(a+b\)` 转为 `$a+b$`，用于行内公式。
- `\[a+b\]` 转为独立的 `$$` 公式块。
- 支持 `equation`、`displaymath`、`math`、`align` 和 `gather` 环境，其中对齐环境会转换为 `aligned` 或 `gathered`。
- 单独选中的 `\frac{a}{b}`、`\sqrt{x}` 等数学命令也可识别并加上公式分隔符。

转换会保留公式内容和选区中的周围文字。已是 `$…$` 写法的内容不会重复转换；普通文字不显示此选项。转换后会由内置 MathJax 离线排版。

## 4. 离线数学公式

公式由应用内置的 MathJax 3.2.2 排版为 SVG，不需要联网或安装公式字体。支持 `$…$`、`$$…$$`、`\(…\)` 和 `\[…\]` 四种分隔符。只需在编辑区输入公式，右侧就会显示结果。

### 行内公式

与正文放在同一行：

```markdown
分数为 $\frac{a_1}{b}$，根式为 $\sqrt{x^2+y^2}$。
```

### 独立公式块

在上下两行分别写 `$$`，适合较长的公式：

```markdown
$$
\int_0^1 x^2\,dx = \frac{1}{3}
$$
```

### 多行对齐与矩阵

```markdown
$$
\begin{aligned}
a+b &= c \\
x &= c-b
\end{aligned}
$$

$$
\begin{pmatrix}
1 & 2 \\
3 & 4
\end{pmatrix}
$$
```

代码块、行内代码中的公式示例保持源码，不会渲染。需要显示普通美元符号时，写成 `\$`。若公式没有显示，请检查分隔符、花括号和命令拼写；裸露的 LaTeX 环境或命令可以先选中，再点击「转换公式」。应用支持常见数学命令，不加载远程扩展；不支持或不完整的公式会保留错误提示或源码。

导出的 HTML 包含公式 SVG 和样式，可以离线查看。PDF 会等待公式排版完成。MathJax 的 Apache 2.0 许可位于 `Vendor/MathJax/LICENSE`。

## 5. 保存和另存为

点击顶部「保存」或按 ⌘S。新文档首次保存时，选择文件夹和文件名。按 ⇧⌘S 可以另存为其他文件。

底部状态栏显示字数、行数、光标所在行、编码和保存状态。看到「修改待保存」时，按 ⌘S；成功保存后会显示「已保存」。应用支持 macOS 文档自动保存，重要修改后仍建议手动保存。

打开 UTF-8 或 UTF-16 文件时会保留原来的编码及换行方式。需要统一编码时，使用「文件 → 以 UTF-8 另存为」。

## 6. 侧栏大纲和文件列表

点击顶部「侧栏」可以显示或隐藏侧栏。

- **大纲**：显示当前文档的标题。点击标题可跳转到相应位置。
- **文件**：点击「选择文件夹…」后，列出该文件夹及子文件夹中的 Markdown 和文本文件。点击文件可打开。

文件夹内容发生变化时，使用「视图 → 刷新文件列表」。

## 7. 从侧栏导出 PDF 或 HTML

侧栏底部的「导出文档」区域提供两个选项。

### 打印 / 导出 PDF

1. 在侧栏的「PDF 页边距」中选择「正常」「较窄」或「极窄」。三档四边留白分别是 25.4 mm、12.7 mm 和 6.35 mm。
2. 点击「打印 / 导出 PDF…」。
3. 在系统打印面板中查看分页预览。
4. 点击面板中的「PDF」菜单，选择「存储为 PDF」。
5. 选择文件名和位置，完成保存。

若需要纸质打印，在该面板中选择打印机并打印。预览和公式尚未排版完成时，侧栏 PDF 按钮会暂时不可用；排版完成后即可打印，公式会保留在 PDF 中。

### 导出 HTML

1. 点击「导出 HTML…」。
2. 选择 `.html` 文件的名称和保存位置。
3. 使用浏览器打开导出的文件，查看排版。

导出会保留标题、表格、代码块等排版。公式会保存为内嵌 SVG，打开导出的 HTML 时无需联网，也无需另外携带 MathJax。HTML 中的本地图片仍引用原文档目录；发送给别人时，需要同时提供图片并调整路径。

## 8. 插入图片、列表和代码

先保存文档，再使用「格式 → 插入本地图片…」选择图片。应用会把图片复制到文档旁的 `assets` 文件夹，并插入相对路径。移动文档时，请同时移动 `assets` 文件夹。

「格式」菜单也提供链接、表格、引用、无序列表、任务列表、代码块、行内代码和删除线。选区浮动菜单还可在文字后插入有序列表。列表回车时会自动续写下一项；任务列表的新项默认未完成；空列表项再按回车会退出列表。

## 9. 查找、替换和撤销

按 ⌘F 打开查找栏，输入关键词，通过上一个或下一个按钮跳转。按 ⌥⌘F 打开替换选项。完成后点击查找栏的「完成」。

按 ⌘Z 撤销最近操作，按 ⇧⌘Z 重做。浮动选项里的格式修改也可以撤销。

## 10. 外观和快捷键

点击顶部「外观」，依次切换跟随系统、浅色和深色。「视图」菜单可调整编辑字号。

- ⌘N：新建；⌘O：打开；⌘S：保存；⇧⌘S：另存为。
- ⌘F：查找；⌥⌘F：查找替换；⌘G：下一个匹配。
- ⌘B：切换加粗；⌘I：切换斜体；⌘E：行内代码；⌘K：链接。
- ⌥⌘1–6：转换为相应级别的标题。
- ⌃⌘1：编辑；⌃⌘2：双栏；⌃⌘3：阅读。
- ⌘\：显示或隐藏侧栏；⌘P：打印 / PDF。
- ⌘Z：撤销；⇧⌘Z：重做。

## 11. 当前支持范围

墨页采用 Markdown 源码编辑加实时预览。当前支持常见 Markdown 和 GFM 格式，支持离线数学公式，尚未加入 Mermaid 和单窗所见即所得编辑。预览会过滤原始 HTML，外部网页链接由默认浏览器打开。

本地图片请放在文档所在目录或子目录中，也可以通过菜单导入。大文件可能需要更多渲染时间。
